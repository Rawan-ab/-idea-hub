# Idea Hub

هذا المستودع يجمع المشاريع والأفكار بشكل منفصل.

## المشاريع الحالية

### 1. Shared Space App
تطبيق Flutter خاص بين شخصين، Invite-only، للصور والرسائل والنوت والمطاعم والأفلام والذكريات ومشاركة الروابط. الهدف: نسخة هدية جاهزة قبل 1 يناير 2027.

- [Project Overview](projects/shared-space-app/README.md)
- [Roadmap](projects/shared-space-app/ROADMAP.md)

### 2. Social Save Library
تطبيق شخصي لحفظ الروابط من TikTok وInstagram وX وغيرها عبر Share → Save to App، ثم تنظيمها وتصنيفها والبحث فيها.

- [Project Overview](projects/social-save-library/README.md)
- [Roadmap](projects/social-save-library/ROADMAP.md)

## طريقة العمل
أي فكرة أو تطوير جديد يضاف داخل مجلد المشروع الخاص به حتى تظل الخطط منفصلة وواضحة.
